# นำเข้าวัสดุรอตรวจทั้งหมดใน Google Apps Script

ใช้กับโปรเจกต์ **Admin** ที่เชื่อม Google Sheet จริงอยู่แล้ว ไม่ต้องสร้างชีทใหม่ และไม่ต้องใช้โปรเจกต์ User

## ไฟล์ที่ต้องคัดลอก

1. เพิ่มไฟล์สคริปต์ `AdminBulkImport.gs` ในโปรเจกต์ Admin
2. แทนที่เนื้อหา HTML `AdminIndex.html` และ `AdminScripts.html` ด้วยไฟล์ล่าสุดในเครื่อง เพื่อเอาข้อความสีเทาออกจากหน้า `ตรวจนำเข้า`

ไฟล์อื่นของ Admin ไม่ต้องเปลี่ยน สำหรับการนำเข้าครั้งนี้ต้องมี `Config.gs`, `Schema.gs`, `SeedData.gs`, `Setup.gs`, `AdminData.gs` และ `AdminActions.gs` ที่ใช้งานอยู่แล้ว

## ลำดับการรัน

1. บันทึกไฟล์ จากตัวเลือกฟังก์ชันบนแถบเครื่องมือ เลือก `previewMaterialBulkImport` แล้วกด **เรียกใช้**
2. เปิด **บันทึกการดำเนินการ** และดูผล JSON: `ok` ต้องเป็น `true`, `blockers` ต้องเป็น `[]`, `sourceRows` ต้องเป็น `134` และ `pending` ควรตรงกับจำนวนรอตรวจในเว็บ Admin
   หากเคยขึ้น `รหัสวัสดุซ้ำหรือว่าง` ให้ใช้ `AdminBulkImport.gs` เวอร์ชันล่าสุดแล้วรัน Preview ใหม่ ตัวนำเข้าจะข้ามเฉพาะแถวแม่แบบที่ไม่มีชื่อ รหัส ยอด ราคา หรือรูปภาพ หากแถวมีข้อมูลแต่รหัสว่าง จะรายงานเลขแถวและตัวอย่างใน `materialRowsWithoutIds` และหยุดก่อนเขียนข้อมูล ห้ามลบแถวนั้นโดยไม่ตรวจ
3. หากผลตรง ให้เลือก `importPendingMaterialReviews` แล้วกด **เรียกใช้** เพียงครั้งเดียว รอจนสถานะ **ดำเนินการเสร็จสิ้น**
4. เปิดบันทึกการดำเนินการอีกครั้ง ดู `approved`, `pendingAfter: 0` และเก็บ `backupUrl` ซึ่งเป็นสำเนา Google Sheet ก่อนนำเข้า
5. ในโปรเจกต์ Admin เลือก **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่ → ทำให้ใช้งานได้** แล้วโหลดหน้า Admin ใหม่ เพื่อให้ข้อความสีเทาหายไป

ฟังก์ชันนี้อ่านจากชีท `ตรวจนำเข้า` ปัจจุบัน แล้วเพิ่มแถวในชีท `วัสดุ`, `รายการวัสดุรายปี` และ `รายการเคลื่อนไหว` ก่อนเปลี่ยนสถานะเป็น `APPROVED` จึงไม่ต้องกดตรวจทีละแถว ยอดสต็อกใช้คอลัมน์ `คงเหลือที่เสนอ` ของรายการนำเข้า และคงค่าต้นทางกับรหัสประเด็นข้อมูลไว้ในชีทรายปีสำหรับตรวจย้อนหลัง

ถ้า Apps Script หยุดกลางทาง ให้รัน `previewMaterialBulkImport` อีกครั้งก่อน แล้วจึงรัน `importPendingMaterialReviews` ซ้ำ ฟังก์ชันจะเชื่อมแถวที่สร้างไว้แล้ว ไม่เพิ่มวัสดุซ้ำ **ห้ามลบแถวหรือแก้รหัสวัสดุเองระหว่างการกู้คืน**

สำคัญ: การนำเข้าครั้งนี้ไม่พิสูจน์ว่า Excel ทุกแถวถูกต้อง แถวที่มี `SOURCE_TOTAL_CONFLICT`, `SOURCE_BALANCE_CONFLICT`, `SOURCE_VALUE_CONFLICT` หรือ `MISSING_PRICE` จะยังมีรหัสประเด็นข้อมูลไว้ให้ตรวจเฉพาะจุดหลังนำเข้า ก่อนใช้เป็นรายงานทางการ
