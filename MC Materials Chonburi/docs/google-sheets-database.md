# ฐานข้อมูล Google Sheets

## วิธีสร้าง

1. ตรวจค่า `SPREADSHEET_ID` และ `ADMIN_EMAILS` ใน `Config.gs`
2. อัปโหลด `Config.gs`, `Schema.gs`, `SeedData.gs`, `InkSeedData.gs`, `Setup.gs` และ `appsscript.json` เข้า Google Apps Script
3. เลือกฟังก์ชัน `createMaterialDatabase` แล้วกด Run
4. อนุญาตสิทธิ์ Google Sheets, Google Drive และข้อมูลอีเมลของบัญชีผู้รัน
5. รัน `validateMaterialDatabase` หลังสร้างเสร็จ

ห้ามแก้ชื่อชีตหรือหัวคอลัมน์ด้วยตนเองหลังระบบเริ่มใช้งาน เพราะโค้ดฝั่ง API จะอ้างอิง schema ชุดนี้ค่ะ

## ตารางที่สร้าง

| ชีต | หน้าที่ |
|---|---|
| ประเภทวัสดุ | รหัสและลำดับประเภทวัสดุ |
| ฝ่ายขอเบิก | ฝ่ายที่ผู้ใช้เลือกและผู้ลงนามประจำฝ่าย |
| ตรวจนำเข้า | staging จาก Excel และสถานะอนุมัติข้อมูลตั้งต้น |
| วัสดุ | master วัสดุ ยอดจริง ยอดรอจ่าย ราคา และรูปภาพ |
| ปีงบประมาณ | รอบปี 1 ตุลาคมถึง 30 กันยายนและสถานะเปิดหรือปิด |
| รายการวัสดุรายปี | ยอดยกมา รับ จ่าย ปรับปรุง ราคา และยอดปลายงวดแยกตามปี |
| รายการเคลื่อนไหว | stock ledger ที่ตรวจสอบย้อนหลังได้ |
| คำขอเบิก | หัวเอกสาร ผู้ขอ ฝ่าย วัตถุประสงค์ สถานะ และผู้ดำเนินการ |
| รายการคำขอเบิก | วัสดุ จำนวนเบิก จำนวนจ่าย และหมายเหตุต่อรายการ |
| หมึก | master หมึก ยอดตั้งต้น ยอดจริง ราคา และรูปภาพ |
| เอกสารหมึก | หัวเอกสารซื้อ เบิก และปรับยอดหมึก |
| รายการเอกสารหมึก | บรรทัดสินค้า จำนวน ราคา และราคารวม |
| เหตุผลการซื้อหมึก | หัวข้อและเหตุผลที่ผู้ดูแลแก้ไขได้ |
| ผู้ลงนามเอกสาร | ผู้สั่งจ่าย ผู้อนุมัติ และผู้รับรองรายงาน |
| ไฟล์สื่อ | metadata ของรูปที่เก็บใน Google Drive |
| ผู้ใช้งาน | รายชื่อผู้ดูแลและสิทธิ์สำหรับการขยายระบบในอนาคต |
| รหัสกันบันทึกซ้ำ | idempotency สำหรับป้องกันคำขอซ้ำ ซ่อนไว้จากผู้ใช้ |
| ประวัติระบบ | Audit Trail ซ่อนไว้จากผู้ใช้ |
| _System | schema version, running sequence และค่าระบบ ซ่อนไว้จากผู้ใช้ |

## ข้อมูลตั้งต้น

- ประเภทวัสดุ 7 ประเภท
- วัสดุที่ยืนยันจาก Excel แล้ว 123 รายการ
- รายการรอตรวจ 11 รายการ
- ปีงบประมาณ 2569
- ฝ่ายบริหารและฝ่ายวิชาการ พร้อมชื่อผู้ลงนาม
- รายชื่อผู้สั่งจ่ายและผู้อำนวยการตามแบบ PDF
- หมึกตั้งต้น 14 รุ่น
- ประวัติซื้อและเบิกหมึกเดิม 68 บรรทัด
- เหตุผลการซื้อหมึกเดิม 2 รายการ
- รหัสเข้าหน้าผู้ใช้จาก `INITIAL_USER_ACCESS_CODE` ถูกเก็บเป็น SHA-256 ใน Script Properties ไม่เก็บเป็นข้อความปกติในชีต

## ความปลอดภัยในการรันซ้ำ

`createMaterialDatabase` เป็น idempotent โดยเพิ่มเฉพาะสิ่งที่ขาดและรักษา sequence เดิมที่สูงกว่าไว้ ไม่ลบแถวธุรกรรม ไม่เขียนทับคำขอเบิก และไม่ย้อนยอดสต็อกค่ะ

หากพบฐานรุ่นเดิม ระบบจะเพิ่มคอลัมน์ใหม่ต่อท้าย เติมค่าเริ่มต้นเฉพาะช่องว่าง และเปลี่ยนหัวคอลัมน์ `จำนวนจอง` เป็น `จำนวนรอจ่าย` โดยคงข้อมูลในแถวเดิมค่ะ
