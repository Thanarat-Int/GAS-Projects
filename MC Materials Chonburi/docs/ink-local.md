# หมึก: การใช้งาน Local

1. กด **เพิ่มหมึก** เพื่อเพิ่มรุ่นที่ยังไม่มี (เริ่มคงเหลือ 0) ไม่ต้องเพิ่มชื่อซ้ำทุกครั้งที่ซื้อ
2. แท็บ **รายการซื้อ** → **เพิ่มรายการซื้อ** เลือกหมึก จำนวน ราคาต่อหน่วย เพิ่มหลายบรรทัดได้ ราคารวมคำนวณเอง
3. แท็บ **รายการเบิกหมึก** → **บันทึกเบิกหมึก** เลือกฝ่ายและรายการ ระบบลดคงเหลือทันทีเมื่อบันทึกสำเร็จ
4. การบันทึกรับ/จ่ายครั้งแรกต้องยืนยันวันเริ่มใช้ยอดและตรวจของจริงกับคงเหลือ Excel ก่อน ไม่รวมประวัติเก่ามาตัดซ้ำ
5. ปุ่ม **แก้ไข/ลบ** ในรายการที่สร้างใหม่มีผลทั้งเอกสาร (ทุกบรรทัดร่วมเลขเอกสาร) และคำนวณประวัติสต็อกใหม่ การเปลี่ยนที่ทำให้ติดลบจะถูกปฏิเสธ
6. ปุ่มแก้ไข/ลบในประวัติ Excel เดิมเปลี่ยนเฉพาะรายงาน ไม่เปลี่ยนยอดตั้งต้น ให้แก้คงเหลือแยกหากยอดตรวจนับผิด
7. แท็บ **คงเหลือ** แก้ชื่อ จำนวนจริง และราคาต่อหน่วยได้ ผลต่างจำนวนถูกเก็บเป็นรายการปรับปรุง ไม่ลบประวัติเดิม ลบชื่อหมึกได้เมื่อคงเหลือเป็น 0 เท่านั้น
8. ทุกการแก้ไข/ลบต้องมีเหตุผล และมีประวัติก่อน–หลังท้ายตาราง ข้อมูลที่ลบเป็น soft-delete ไม่ลบออกจากไฟล์ฐานข้อมูล

## ข้อมูลและการสำรอง

- `local-data/ink.json` คือฐานข้อมูลหมึกถาวร ห้ามลบขณะใช้งาน
- `local-data/ink.json.bak` เป็นรุ่นก่อนการบันทึกล่าสุด ไม่ใช่สำรองระยะยาว
- ใช้ปุ่ม **สำรองข้อมูลหมึก** ดาวน์โหลด JSON ไปเก็บต่างเครื่องเป็นประจำ
- กู้คืนด้วยผู้ดูแล: หยุด server, สำรองไฟล์ปัจจุบันแยกไว้, แทนที่ `local-data/ink.json` ด้วยสำเนาที่ตรวจสอบแล้ว, เปิด server และตรวจยอด/ประวัติ ไม่กู้คืนทับขณะ server ทำงาน
- เปิด server เพียง instance เดียวต่อไฟล์ฐานข้อมูลเดียวกัน การทดสอบใช้ `INK_DATA_PATH` แยกไฟล์
- ปีงบประมาณคำนวณจากวันที่ (ต.ค.–ก.ย.) ปีใหม่ปรากฏจากรายการที่บันทึกจริง ไม่สร้างเอกสารล่วงหน้า
- วันที่รายการใหม่ต้องไม่ก่อนวันเริ่มใช้ยอดและรายการล่าสุด แก้เอกสารย้อนหลังได้ในลำดับวันที่เดิม ไม่ย้ายเลขเอกสารข้ามปี
- ราคาคงคลังใช้ราคาต่อหน่วยล่าสุดตามลำดับรายการ/การปรับราคา ไม่ใช่ FIFO หรือถัวเฉลี่ย

## ขอบเขตความพร้อม

ระบบนี้เป็น **Local Admin** บน `127.0.0.1` ยังไม่เชื่อม GAS/Google Sheets และยังไม่มีระบบยืนยันตัวบุคคลหลายผู้ใช้ ห้ามเปิดพอร์ตสู่ภายนอกเพื่อใช้ร่วมกันทันที

API หมึกตรวจสิทธิ์จาก `INK_LOCAL_ROLE` ฝั่ง server (`admin` โดยปริยาย; `user` อ่านอย่างเดียว) ไม่รับ role จากแบบฟอร์ม นี่เป็นโหมดเครื่อง ไม่ใช่ระบบ login แยกคน ต้องเชื่อมตัวตนและสิทธิ์จริงก่อน deploy

ข้อมูลวัสดุส่วนอื่นยังใช้ store ในหน่วยความจำตามระบบเดิม ความถาวรที่เพิ่มครั้งนี้ครอบคลุมเฉพาะหมึก จึงยังไม่ถือว่าโปรเจกต์ทั้งหมดพร้อมทดแทน Excel 100%
