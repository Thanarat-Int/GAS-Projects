# Google Apps Script User Web App

ใช้โปรเจกต์ Apps Script ใหม่ `MC Materials User` ที่เป็น Standalone และเชื่อมกับ Google Sheet เดิม ไม่ต้องสร้างชีทเพิ่ม

## ตั้งค่าก่อนคัดลอก

เปิด `UserConfig.gs` ในเครื่อง แล้วเปลี่ยนค่า `SPREADSHEET_ID` เป็นค่าเดียวกับ `SPREADSHEET_ID` ใน `Config.gs` ของโปรเจกต์ Admin ที่ Deploy แล้ว ห้ามใช้ Spreadsheet ID จากไฟล์ `Config.gs` ในเครื่องโดยไม่ตรวจ เพราะอาจเป็นคนละชีท

กำหนดรหัสเข้าใช้งานที่คาดเดายากใน `ACCESS_CODE` และใช้ค่าเดียวกับ `INITIAL_USER_ACCESS_CODE` ของฝั่ง Admin รหัสจะถูกตรวจสอบบนเซิร์ฟเวอร์และไม่ถูกส่งไปกับ HTML อย่างไรก็ตาม รหัสร่วมไม่ใช่ระบบยืนยันตัวตนรายบุคคล ต้องแจกเฉพาะผู้ใช้ภายในและเปลี่ยนทันทีหากรั่วไหล

## ไฟล์ที่ต้องเพิ่มในโปรเจกต์ User

ลบหรือปล่อยไฟล์ `รหัส.gs` ที่มี `myFunction` ไว้ก็ได้ แต่ไม่ต้องคัดลอกไฟล์ Admin, Setup, SeedData หรือ Schema มาในโปรเจกต์นี้

สร้างสคริปต์ 4 ไฟล์:

1. `UserConfig.gs`
2. `UserData.gs`
3. `UserRequests.gs`
4. `UserWeb.gs`

สร้าง HTML 6 ไฟล์ (ตั้งชื่อโดยไม่ต้องพิมพ์ `.html` ในช่องชื่อของ Apps Script):

1. `UserIndex.html`
2. `UserLogo.html`
3. `UserStyles.html`
4. `UserBridge.html`
5. `UserAccessScripts.html`
6. `UserScripts.html`

ไม่ต้องคัดลอก `web/user.html`, `web/user.js` หรือโฟลเดอร์ `web/assets` เพราะชุด HTML ด้านบนรวมไฟล์ใช้งานไว้แล้ว

## ทดสอบและ Deploy

1. บันทึกไฟล์ทั้งหมด ตรวจว่า `UserConfig.gs` ใส่ Spreadsheet ID ของชีทจริงแล้ว
2. Deploy เป็น Web App โดยเลือก `เรียกใช้ในชื่อ: ฉัน` และ `ผู้มีสิทธิ์เข้าถึง: ทุกคน` เฉพาะเมื่อพร้อมแจก URL ให้ผู้เบิก
3. เปิด URL `/exec` ในหน้าต่างไม่ระบุตัวตน ทดสอบว่าต้องกรอกรหัสก่อนเห็นรายการวัสดุ
4. กรอกรหัสที่ตั้งไว้ใน `UserConfig.gs`, เลือกวัสดุที่มีคงเหลือมากกว่า 1, ส่งคำขอทดลอง 1 รายการ แล้วตรวจว่าคำขอใหม่ขึ้นในหน้า Admin เป็นสถานะ `รออนุมัติ`
5. ไม่แจก URL ของ Admin ให้ผู้เบิก

คำขอจาก User ใช้เลขอ้างอิงขึ้นต้น `REQ-<ปี>-U...` เพื่อไม่ให้ชนกับเลขลำดับ `REQ-<ปี>-0001` ของ Admin เมื่อสองโปรเจกต์เขียนลงชีทเดียวกัน

## การแก้หน้าเว็บภายหลัง

หลังแก้ไฟล์ต้นฉบับใน `web` ให้รัน `npm run build:gas-user` แล้วคัดลอกไฟล์ HTML 5 ไฟล์ที่สร้างใหม่ (ไม่รวม `UserBridge.html` หากไม่ได้แก้) ไปแทนใน Apps Script และสร้าง Deployment เวอร์ชันใหม่

หมายเหตุ: Google Apps Script สองโปรเจกต์ไม่มี ScriptLock ร่วมกัน ระบบใช้รหัสคำขอ User ที่ไม่ชนกับ Admin และเพิ่มแถวด้วย `appendRow` แต่ควรทดสอบการส่งคำขอจำนวนมากในสภาพแวดล้อมจริงก่อนเปิดใช้งานวงกว้าง
