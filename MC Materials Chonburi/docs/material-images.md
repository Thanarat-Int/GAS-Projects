# Material photos and ink pagination

- Browser accepts PNG, JPG/JPEG and WebP source files up to 20 MiB. It decodes and resizes to a maximum 1024-pixel edge, then sends a PNG to the local upload endpoint (maximum processed image 5 MiB). Source originals are not retained.
- White-background removal is optional and enabled initially. It removes near-white pixels connected to the image border, not arbitrary scenes. Use an already transparent PNG/WebP for complex backgrounds or white objects touching the image edge; disable removal if it erases part of the product.
- Existing items use transparent, category-based SVG placeholders. Table thumbnails are 48 by 48 pixels; editing previews are 56 by 56 pixels (44 on small screens). They are illustrations, not verified product photographs.
- The editor accepts pasted image files through the user's Ctrl+V action anywhere within the open form. Click the preview first when needed. Ordinary text paste remains unchanged; copying a URL/HTML is not an image paste. Choose File remains available. Pasted and selected files share size/type validation, resize and optional background removal; neither is saved until the parent form is submitted.
- Files and item-to-image links are stored under `local-data/images`. Preserve this entire directory when backing up or moving the local app. The older ink JSON backup does not include image files. `IMAGE_DATA_PATH` overrides the directory for isolated tests.
- The image endpoint checks origin, file signature, size and dimensions. Only generated PNG URLs are accepted as item image references; arbitrary remote URLs and uploaded SVG are not accepted.
- Image linkage changes when the parent form saves successfully. Cancelling preserves the existing linkage. Failed parent saves can leave unreferenced content-addressed image files; do not automatically delete them without a retention policy.
- Stock values at or below 10 are red, including zero. Purchase/withdrawal quantities are not mistaken for stock balances.
- Ink purchase groups display newest fiscal year/date first, five groups per page. Each group's table, withdrawals and balances display ten rows per page. Search/filter changes reset pages. Totals cover the entire filtered set, not only the current page.
- This is local implementation, not GAS deployment. Existing material records are still in-memory; do not restart the server after user material edits without a migration/persistence plan. Images alone persist across restarts. A future GAS adapter must store image files in an authorized storage destination and preserve stable item IDs and access controls.
